## 寫測試前必讀

### 這個框架的運作方式

想像你在操作手機 APP：
1. **打開 APP** → 用 `Navigator` 初始化
2. **找到按鈕** → 用 `Page Object` 定義元件位置
3. **點擊按鈕** → 用 `.click()` 操作
4. **檢查結果** → 用 `assert` 驗證

### 三個核心概念

```
測試腳本 (test_login.py)
    ↓ 使用
Navigator (導航器)
    ↓ 找到
Page Object (頁面物件，例如：登入頁)
    ↓ 操作
元件 (按鈕、輸入框等)
```

## 寫一個簡單的測試

### 範例：測試登入功能

```python
import pytest
from module.mobile.navigator import Navigator

def test_login():
    # 步驟 1: 開啟 APP（iOS 中文版）
    navigator = Navigator().ios.zh
    
    # 步驟 2: 輸入帳號密碼
    navigator.ios_login_page.id_input().send_keys("65141474")
    navigator.ios_login_page.user_name().send_keys("admin01")
    navigator.ios_login_page.user_pwd().send_keys("Ab123456")
    
    # 步驟 3: 點擊登入按鈕
    navigator.ios_login_page.login_btn().click()
    
    # 步驟 4: 檢查是否登入成功
    assert navigator.ios_overview_page.overview().is_visible()
```

### 程式碼解釋

| 程式碼 | 意思 |
|--------|------|
| `Navigator().ios.zh` | 開啟 iOS 中文版 APP |
| `navigator.ios_login_page` | 找到「登入頁面」 |
| `.id_input()` | 找到「ID 輸入框」 |
| `.send_keys("65141474")` | 輸入文字 |
| `.click()` | 點擊 |
| `.is_visible()` | 檢查是否看得到 |
| `assert` | 驗證結果（如果失敗會報錯） |

### 執行測試

```bash
# 在終端機執行
pytest testcase/ios/test_login.py --platform=ios
```

## 建立新的頁面元件

當你要測試一個新功能時，需要三個步驟：

### 📍 步驟 1: 建立 Page Object（定義元件在哪裡）

在 `page/ios/` 資料夾建立新檔案，例如 `settings.py`：

```python
from module.mobile.component.base_object import BaseObject
from module.mobile.component.basic_component import BasicComponent
from module.mobile.device_manager import DeviceManager
from appium.webdriver.common.appiumby import AppiumBy

class iOSSettingsPage(BaseObject):
    def __init__(self, role=None):
        super().__init__()
        self.set_remark("設定頁")
        self.driver = DeviceManager.get_driver(role=role)
    
    # 定義「登出按鈕」在哪裡
    def logout_btn(self):
        return BasicComponent(
            lambda: self.driver.find_element(
                AppiumBy.ACCESSIBILITY_ID,  # 用什麼方式找
                "登出"                       # 找什麼內容
            ),
            remark=f"{self.remark()} > 登出按鈕"  # 給這個元件取名字
        )
```

**重點說明**：
- `AppiumBy.ACCESSIBILITY_ID` = 用「無障礙 ID」找元件（最常用）
- `"登出"` = 元件的名稱
- `remark` = 幫助你在 log 中看懂是哪個元件

### 📍 步驟 2: 註冊到 Navigator（讓測試找得到）

編輯 `module/mobile/navigator_ios_zh.py`：

```python
# 1. 在檔案最上面加入 import
from page.ios.settings import iOSSettingsPage

class NavigatoriOSZh:
    def __init__(self, role=None):
        self.role = role
        # 2. 初始化變數（用兩個底線開頭）
        self.__ios_settings_page = None
    
    # 3. 建立 property（讓外面可以用 navigator.ios_settings_page 存取）
    @property
    def ios_settings_page(self) -> iOSSettingsPage:
        if self.__ios_settings_page is None:
            self.__ios_settings_page = iOSSettingsPage()
        return self.__ios_settings_page
```

**為什麼要這樣做？**
- 這樣測試才能用 `navigator.ios_settings_page` 存取
- 避免重複建立物件（第一次建立後會記住）

### 📍 步驟 3: 在測試中使用

```python
def test_logout():
    navigator = Navigator().ios.zh
    
    # 現在可以用了！
    navigator.ios_settings_page.logout_btn().click()
```

## 多裝置測試

### 什麼時候需要多裝置？

例如：測試 OTP 驗證碼功能
- **裝置 A**：產生驗證碼
- **裝置 B**：輸入驗證碼

### 步驟 1: 設定裝置資訊

在 `data/json/devices.json` 設定兩台裝置：

```json
{
  "defaultRole": "old",
  "devices": {
    "old": {
      "platform": "ios",
      "udid": "00008150-00154C6C0E46401C",
      "wdaLocalPort": 8102,
      "bundleId": "com.cathaybk.geb",
      "appiumPort": "4723"
    },
    "new": {
      "platform": "ios",
      "udid": "1C023E72-72E7-4A64-91A0-15484676A023",
      "wdaLocalPort": 8103,
      "bundleId": "com.cathaybk.geb",
      "appiumPort": "4723"
    }
  }
}
```

**重點**：
- `old` 和 `new` 是裝置的「代號」（你可以自己取名）
- `wdaLocalPort` 每台裝置要不同

### 步驟 2: 建立支援多裝置的 Page Object

```python
# page/ios/otp_multi.py
from module.mobile.component.basic_component import BasicComponent
from module.mobile.device_manager import DeviceManager
from appium.webdriver.common.appiumby import AppiumBy

class iOSOTPPageMulti:
    def __init__(self, role):
        self.role = role  # 記住是哪台裝置
        self.driver = DeviceManager.get_driver(role=role)  # 取得對應裝置的 driver
    
    def otp_display(self):
        return BasicComponent(
            lambda: self.driver.find_element(
                AppiumBy.ACCESSIBILITY_ID, 
                "驗證碼"
            ),
            remark=f"[{self.role}] OTP頁 > 驗證碼顯示"
        )
    
    def otp_input(self):
        return BasicComponent(
            lambda: self.driver.find_element(
                AppiumBy.ACCESSIBILITY_ID, 
                "輸入驗證碼"
            ),
            remark=f"[{self.role}] OTP頁 > 驗證碼輸入框"
        )
```

### 步驟 3: 註冊到 Navigator（多裝置版）

```python
# module/mobile/navigator_ios_zh.py
from page.ios.otp_multi import iOSOTPPageMulti

class NavigatoriOSZh:
    def __init__(self, role=None):
        self.role = role
        self.__ios_otp_page_mu = {}  # 用字典存多個裝置
    
    # 注意：這裡用方法，不是 @property
    def ios_otp_page_mu(self, role: str) -> iOSOTPPageMulti:
        if role not in self.__ios_otp_page_mu:
            self.__ios_otp_page_mu[role] = iOSOTPPageMulti(role=role)
        return self.__ios_otp_page_mu[role]
```

**單裝置 vs 多裝置的差異**：

| 項目 | 單裝置 | 多裝置 |
|------|--------|--------|
| 初始化變數 | `self.__page = None` | `self.__page_mu = {}` |
| 存取方式 | `@property` | 一般方法 |
| 使用方式 | `navigator.page` | `navigator.page_mu(role="old")` |

### 步驟 4: 撰寫多裝置測試

```python
def test_otp_two_devices():
    navigator = Navigator().ios.zh
    
    # 舊裝置：產生驗證碼
    old_page = navigator.ios_otp_page_mu(role="old")
    old_page.generate_otp_btn().click()
    otp_code = old_page.otp_display().text  # 取得驗證碼
    
    # 新裝置：輸入驗證碼
    new_page = navigator.ios_otp_page_mu(role="new")
    new_page.otp_input().send_keys(otp_code)  # 輸入驗證碼
    new_page.verify_btn().click()
    
    # 驗證成功
    assert new_page.success_msg().is_visible()
```

## 常用操作速查

### 元件操作

```python
# 點擊
component.click()

# 輸入文字
component.send_keys("文字內容")

# 清空內容
component.clear()

# 取得文字
text = component.text

# 取得屬性值
value = component.value
```

### 檢查與驗證

```python
# 檢查是否可見（回傳 True/False）
if component.is_visible():
    print("看得到")

# 斷言必須可見（失敗會報錯）
component.assert_visible()

# 斷言必須不可見
component.assert_invisible()

# 檢查是否可點擊
if component.is_clickable():
    component.click()
```

### 條件判斷

```python
# 處理可能出現的彈窗
if navigator.ios_login_page.dialog().is_visible():
    navigator.ios_login_page.confirm_btn().click()

# 處理多種情況
if navigator.ios_login_page.error_msg().is_visible():
    print("登入失敗")
elif navigator.ios_overview_page.overview().is_visible():
    print("登入成功")
```

### 截圖

```python
# 截圖並附加到報告
navigator.ios_overview_page.save_screenshot(
    case='photo',
    name='登入成功畫面',
    attach_jpg=True,
    remove=True
)
```

### 尋找元件的方式

#### iOS 常用方法

```python
# 方法 1: 用無障礙 ID（最推薦）
AppiumBy.ACCESSIBILITY_ID, "登入"

# 方法 2: 用 XPath
AppiumBy.XPATH, '//XCUIElementTypeButton[@name="登入"]'

# 方法 3: 用 iOS Predicate（進階）
AppiumBy.IOS_PREDICATE, 'name == "登入" AND type == "XCUIElementTypeButton"'
```

#### Android 常用方法

```python
# 方法 1: 用 Resource ID（最推薦）
AppiumBy.ID, "com.example:id/login_button"

# 方法 2: 用無障礙 ID
AppiumBy.ACCESSIBILITY_ID, "登入"

# 方法 3: 用 XPath
AppiumBy.XPATH, '//android.widget.Button[@text="登入"]'
```

## 常見問題

### ❓ 為什麼要用 Navigator？

**不用 Navigator（❌ 錯誤）**：
```python
# 每次都要自己建立 Page Object
login_page = iOSLoginPage()
login_page.login_btn().click()

overview_page = iOSOverviewPage()
overview_page.overview().is_visible()
```

**用 Navigator（✅ 正確）**：
```python
# 只要建立一次，所有頁面都能用
navigator = Navigator().ios.zh
navigator.ios_login_page.login_btn().click()
navigator.ios_overview_page.overview().is_visible()
```

### ❓ 單裝置和多裝置有什麼差別？

| 項目 | 單裝置 | 多裝置 |
|------|--------|--------|
| 使用情境 | 一般功能測試 | OTP、轉帳通知等需要兩台手機的測試 |
| Page Object | `__init__(self, role=None)` | `__init__(self, role)` |
| Navigator 註冊 | 用 `@property` | 用方法 + 字典 |
| 測試中使用 | `navigator.page` | `navigator.page_mu(role="old")` |

### ❓ 建立新頁面的檢查清單

- [ ] 1. 在 `page/ios/` 或 `page/android/` 建立 Page Object 檔案
- [ ] 2. 定義元件方法（每個按鈕、輸入框都要定義）
- [ ] 3. 在對應的 Navigator 檔案中 import
- [ ] 4. 在 Navigator 的 `__init__` 中初始化變數
- [ ] 5. 建立 `@property` 方法（單裝置）或一般方法（多裝置）
- [ ] 6. 在測試中用 `navigator.page_name` 存取

### ❓ 如何知道元件的定位方式？

使用 Appium Inspector：
1. 連接裝置
2. 開啟 Appium Inspector
3. 點選要測試的元件
4. 查看右側的屬性（name、resource-id 等）
5. 選擇最穩定的屬性來定位

## 總結

### 寫測試的三步驟

1. **建立 Page Object** → 告訴程式「元件在哪裡」
2. **註冊到 Navigator** → 讓測試「找得到頁面」
3. **撰寫測試** → 用 `navigator.page.component()` 操作

### 記住這些重點

- ✅ 所有測試都用 `Navigator` 開始
- ✅ 每個新頁面都要註冊到 Navigator
- ✅ 單裝置用 `@property`，多裝置用方法
- ✅ 用 `assert` 驗證結果
- ✅ 適時截圖記錄測試過程

### 遇到問題時

1. 檢查 Page Object 是否正確定義
2. 檢查是否已註冊到 Navigator
3. 檢查元件定位方式是否正確
4. 查看 log 了解錯誤訊息
