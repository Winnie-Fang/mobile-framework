# 移動端自動化測試案例開發指南

## 專案架構概述

本專案基於 Appium + Pytest 的移動端測試框架，支援 iOS 和 Android 雙平台測試。採用 Page Object Model (POM) 設計模式，實現測試邏輯與頁面元素的解耦。

### 核心架構層次

```
測試案例 (testcase/)
    ↓ 使用
Navigator (導航器)
    ↓ 定位
Page Object (頁面物件)
    ↓ 操作
BasicComponent (基礎元件)
    ↓ 驅動
Appium Driver
```

### 關鍵目錄結構

- `page/android/` & `page/ios/`: 頁面物件定義
- `testcase/android/` & `testcase/ios/`: 測試案例實現
- `module/mobile/navigator.py`: 導航器入口
- `module/mobile/navigator_ios_zh.py`: iOS 中文導航器
- `data/json/devices.json`: 多裝置配置

## Page Object 設計模式

### 頁面物件基本結構

每個頁面物件繼承 `BaseObject`，並定義頁面上的元素定位器：

```python
from module.mobile.component.base_object import BaseObject
from module.mobile.component.basic_component import BasicComponent
from module.mobile.device_manager import DeviceManager
from appium.webdriver.common.appiumby import AppiumBy

class iOSLoginPage(BaseObject):
    def __init__(self, role=None):
        super().__init__()
        self.set_remark("登入頁")  # 設定頁面名稱
        self.driver = DeviceManager.get_driver(role=role)  # 獲取驅動
    
    def element_name(self):
        return BasicComponent(
            lambda: self.driver.find_element(
                AppiumBy.ACCESSIBILITY_ID,  # 定位策略
                "元素標識"                   # 定位值
            ),
            remark=f"{self.remark()} > 元素描述"  # 元素描述
        )
```

### 元素定位策略

| 策略 | 說明 | 適用場景 |
|------|------|----------|
| `AppiumBy.ACCESSIBILITY_ID` | 無障礙標識 | iOS/Android 通用，推薦首選 |
| `AppiumBy.XPATH` | XPath 路徑 | 複雜定位，跨層級元素 |
| `AppiumBy.IOS_PREDICATE` | iOS 謂詞 | iOS 專用，效能較好 |
| `AppiumBy.IOS_CLASS_CHAIN` | iOS 類別鏈 | iOS 專用，階層定位 |

### 元素操作方法

```python
# 點擊操作
element.click()

# 文字輸入
element.send_keys("輸入內容")

# 清空內容
element.clear()

# 獲取文字
text = element.text

# 檢查可見性
is_visible = element.is_visible()

# 斷言操作
element.assert_visible()      # 斷言可見
element.assert_invisible()    # 斷言不可見
element.assert_clickable()    # 斷言可點擊
```

## 單裝置測試案例開發

### 基本測試結構

```python
import pytest
import allure
from module.mobile.navigator import Navigator

@pytest.mark.ios_login
@allure.epic("iOS")
@allure.feature("登入功能")
@allure.title("一般登入流程")
def test_ios_login_general():
    # 1. 初始化導航器
    navigator = Navigator().ios.zh
    
    # 2. 驗證初始狀態
    navigator.ios_login_page.login_slogan().assert_visible()
    
    # 3. 執行操作步驟
    navigator.ios_login_page.id_input().click()
    navigator.ios_login_page.id_input().send_keys("65141474")
    navigator.ios_login_page.user_name().send_keys("admin01")
    navigator.ios_login_page.user_pwd().send_keys("Ab123456")
    navigator.ios_login_page.login_btn().click()
    
    # 4. 處理條件分支
    if navigator.ios_login_page.dialog_common_message().is_visible():
        navigator.ios_login_page.dialog_login_btn().click()
    
    # 5. 驗證結果
    navigator.ios_overview_page.overview().assert_visible()
```

### 多裝置頁面物件設計

```python
class iOSOTPPageMulti(BaseObject):
    def __init__(self, role):
        super().__init__()
        self.role = role  # 裝置角色標識
        self.set_remark(f"[{role}] OTP頁")
        self.driver = DeviceManager.get_driver(role=role)
    
    def otp_input(self):
        return BasicComponent(
            lambda: self.driver.find_element(
                AppiumBy.ACCESSIBILITY_ID, "驗證碼輸入"
            ),
            remark=f"{self.remark()} > 驗證碼輸入框"
        )
```

### 多裝置導航器註冊

```python
class NavigatoriOSZh:
    def __init__(self, role=None):
        self.role = role
        self.__otp_page_mu = {}  # 多裝置頁面物件字典
    
    def ios_otp_page_mu(self, role: str) -> iOSOTPPageMulti:
        if role not in self.__otp_page_mu:
            self.__otp_page_mu[role] = iOSOTPPageMulti(role=role)
        return self.__otp_page_mu[role]
```

### 多裝置測試實現

```python
def test_otp_cross_device():

    # 裝置A：產生驗證碼
```

1. **靜態文字定位**:

```python
def input_field(self):
    return BasicComponent(
        lambda: self.driver.find_element(

        remark=f"{self.remark()} > 輸入框"
```

3. **iOS 謂詞定位**:

```python
def button(self):

        remark=f"{self.remark()} > 按鈕"
    )
```

## 頁面物件建立流程

建立新的頁面物件需要三個步驟：

#### 步驟1: 建立Page Object檔案

在對應平台目錄下建立頁面物件檔案：

```python
# page/ios/new_page.py
from module.mobile.component.base_object import BaseObject
from module.mobile.component.basic_component import BasicComponent
from module.mobile.device_manager import DeviceManager
from appium.webdriver.common.appiumby import AppiumBy

class iOSNewPage(BaseObject):
    def __init__(self, role=None):
        super().__init__()
        self.set_remark("新頁面")
        self.driver = DeviceManager.get_driver(role=role)
    
    def example_element(self):
        return BasicComponent(
            lambda: self.driver.find_element(
                AppiumBy.ACCESSIBILITY_ID, "元素標識"
            ),
            remark=f"{self.remark()} > 範例元素"
        )
```

#### 步驟2: 在Navigator中註冊頁面物件

編輯對應的navigator檔案，註冊新頁面：

```python
# module/mobile/navigator_ios_zh.py
from page.ios.new_page import iOSNewPage  # 新增import

class NavigatoriOSZh:
    def __init__(self, role=None):
        self.role = role
        self.__ios_new_page = None  # 新增私有變數
    
    @property
    def ios_new_page(self) -> iOSNewPage:  # 新增property
        if self.__ios_new_page is None:
            self.__ios_new_page = iOSNewPage()
        return self.__ios_new_page
```

#### 步驟3: 在測試案例中使用

```python
# testcase/ios/test_new_feature.py
import pytest
from module.mobile.navigator import Navigator

def test_new_feature():
    navigator = Navigator().ios.zh
    
    # 使用新頁面物件
    navigator.ios_new_page.example_element().click()
    navigator.ios_new_page.example_element().assert_visible()
```
